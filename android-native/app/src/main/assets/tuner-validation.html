调音验证方法

能复现的测试，比精度口号更有用。这里说明当前验证范围，以及老师和学生可以怎样检查自己的设备。

截至 2026 年 10 月 7 日，本轮修改已有合成声音和本机浏览器证据；真实手机、现场乐器、蓝牙麦克风和安卓安装包的完整验收尚未完成。合成结果不能作为手机实录精度保证。

我们已经检查什么

660 组合成单帧样例覆盖 44.1、48、96 kHz 采样率，C2–C6 范围内的代表音、偏音、衰减、泛音与白噪声。无噪声样例最大误差约 0.52 音分；全部样例最大误差约 9.70 音分，包含较强混合噪声。

本机浏览器音频管线已检查 E2 标准音、偏低及偏高 20 音分、泛音混噪、纯噪声、静音、固定目标和自动换弦。启动与取消、停止释放输入、参考音暂停收音另有行为检查。

这些检查证明对应样例和流程通过，不证明所有音色、房间或设备都同样可靠；一次瞬时读数也不等于已经调准。

在自己的设备上复现

  1. 先固定目标。选择乐器和一根弦，标准音 A4 与老师要求一致。一次弹一根弦，止住其他弦；先在安静房间检查。
  2. 静音与杂音。开始后不发声，再轻敲桌面或制造环境杂音。页面应等待有效单音，不能凭杂音显示“已调准”。
  3. 偏低与偏高。使用另一台设备上的可靠参考音源，先播放目标音，再播放已知偏低/偏高的音。负音分应在左侧，正音分在右侧；相同参考条件重复三次。
  4. 错误音与八度。固定目标 E2，输入明显不同的音或 E3。固定目标不能把错误八度当成 E2 已调准。自由检测与固定目标的显示规则不同，测试时记录所用模式。
  5. 停止与参考音。停止发声后绿色成功状态应清除。播放本页参考音时收音应暂停；停止调音或将页面切到后台后，应停止输入。
  6. 真实乐器。分别测试短拨弦、衰减和持续长音，再测试正常琴房背景声音。记录读数是否能稳定、开始到稳定的大致时间，以及是否出现错误音名；别只记录一次最好结果。

目标频率的 ±20 音分可以用 目标频率 × 2^(±20/1200) 生成。用独立声源或已授权的测试录音；本页自己的参考音会暂停收音，不能用于自我验收。

检查源码与自动测试

项目：educationmusicbox GitHub 仓库。本页说明对应本轮本地修改；这些修改尚未推送或发布，远程仓库可能还没有相同版本。

取得包含本轮修改的项目目录后，可以运行 node quality/tuner-signal-check.js 检查合成样例；运行 node quality/tuner-input-check.js 检查输入启动、取消与释放。浏览器合成输入夹具位于 quality/tuner-browser-check.html，须从本机网页服务打开。

基础调音无需注册。默认不收集录音；自愿体验统计仅统计尝试结果，不能用于证明音准精度。
