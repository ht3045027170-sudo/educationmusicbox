# 海棠艺考训练系统

本目录承载海棠艺考的乐理、听记、视唱、模拟考试和学习记录，与海棠音乐使用独立账号和业务数据。

## 第一阶段结构

- `gaokao-state.js`：独立学生档案、答题、掌握度、错题、训练场次和 Obsidian 导出。
- `gaokao-app.js`：模式入口、训练首页、乐理分类训练、解析、上一题/下一题及自适应抽题。
- `gaokao.css`：独立的专业考试训练界面和响应式样式。
- `database/theory.json`：广东统考乐理分类题库。
- `database/theory-bank.js`：与 `theory.json` 同步的离线加载镜像，保证直接打开 HTML 时仍可使用完整题库。
- `database/dictation.json`：听写分类与考试边界。
- `database/sight_singing.json`：视唱分类与考试边界。
- `database/mock_exam.json`：75 分钟、40 题模拟考试蓝图。
- `database/mistake.json`：错题数据结构说明；真实错题保存在独立本地状态中。

## 数据边界

- 高考系统本地存储键：`hetian_gaokao_state_v1`
- 普通工具箱原有数据键保持不变。
- 第一阶段不把听写、视唱或模拟考试显示成已经完成；它们保留真实的数据与页面扩展接口。
